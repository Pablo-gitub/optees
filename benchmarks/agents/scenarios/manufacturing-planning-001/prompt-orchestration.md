# Orchestration prompt

The attached workbook contains operational and historical-demand data for a
fictitious manufacturing company. Estimate next-period demand for each product
from its corresponding historical sheet and the values in `Next Period`. Then
determine the most profitable feasible integer production plan using those
forecasts as demand upper bounds.

Choose and orchestrate the appropriate Optees capabilities autonomously.
Inspect every capability before formulating its payload and validate every
exact versioned payload before execution. Clearly separate observed workbook
data, model predictions, optimization decisions, assumptions, mathematical
status, and independent validation. Do not silently replace missing values or
claim that a forecast is certain.

Create a management report in DOCX and PDF explaining the complete workflow,
forecast results, recommended quantities, expected contribution, resource
utilization, binding constraints, uncertainty, limitations, and validation
status.
