# Single-solver prompt

The attached workbook contains operational data for a fictitious manufacturing
company. Use the `Direct Demand Plan` values to determine the production plan
that maximizes total contribution for the next period without exceeding any
available resource or violating product limits and commitments.

Use the available Optees tools. Inspect the relevant capability, formulate and
validate the exact versioned payload, execute it, and report mathematical
status separately from independent validation. Do not invent missing data and
do not use the historical-demand sheets in this first task.

After solving, create a management report in DOCX and PDF containing an
executive summary, recommended quantities, expected contribution, resource
utilization, binding constraints, assumptions, limitations, and Optees
validation status.
